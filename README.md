## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/Gokulakrishnan064/Gokulakrishnan_portfolio.git
```

### Navigate to Project

```bash
cd Gokulakrishnan_portfolio
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```
